# Getting help

1. **Read the docs.** Each library has a site with a live demo or docs at `https://<name>.ghostpaw.dev/docs/`, plus `README.md`, `docs/HUMAN.md` (for developers) and `docs/LLM.md` (for agents) in its repo. An overview of all seven is at [ghostpaw.dev](https://ghostpaw.dev/) and in [llms.txt](https://ghostpaw.dev/llms.txt).
2. **Ask a question.** Open an issue with the question form in the library's repo. Include the package version, Node version and the surface you use (library, MCP server, CLI or skill).
3. **Report a bug.** Use the bug form. A failing snippet or test gets the fastest fix.
4. **Report a vulnerability.** Follow [SECURITY.md](SECURITY.md). Do not open a public issue.

The libraries are maintained by one person, so answers can take a few days.
